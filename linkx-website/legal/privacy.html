LinkX 隐私政策

本政策说明 Yangleduo（以下简称「我们」）如何收集、使用、存储与保护你在使用 LinkX 产品与服务时的个人信息。

导言

LinkX 是由 Yangleduo 提供的企业级即时通讯与协同平台（包括桌面客户端、管理后台及相关服务，以下简称「LinkX」或「本服务」）。我们深知个人信息对你的重要性，并将按照合法、正当、必要和诚信原则处理你的个人信息。

请在使用 LinkX 前仔细阅读本政策。当你注册、登录或使用 LinkX，即表示你已充分理解并同意我们按照本政策处理你的个人信息。若你不同意本政策，请停止使用本服务。

本政策适用于 LinkX 客户端、Web 管理端及我们提供的相关功能与服务。企业管理员通过后台处理的员工信息，亦应遵守本政策及所在组织的内部规定。

一、我们收集的信息

为实现即时通讯、协同办公与账号安全，我们可能收集以下信息：

1.1 账号注册与登录

  • 你主动提供的账号、昵称、密码、邮箱、手机号码等注册信息；
  • 登录时产生的设备型号、操作系统版本、应用版本、IP 地址、登录时间等日志信息；
  • 为保障账号安全，我们可能使用图形验证码、登录风控策略识别异常登录行为。

1.2 即时通讯与社交

  • 你发送或接收的文字、图片、语音、视频、文件等消息内容；
  • 好友关系、群聊成员、群名称、群公告等群组信息；
  • 头像、个性签名、LinkX ID 等公开或半公开资料；
  • 友链动态、点赞、评论等社交互动信息（如你使用该功能）。

1.3 音视频会议

  • 发起或接听语音、视频通话时的信令与连接状态信息；
  • 在多人会议场景下，为建立 WebRTC 连接可能处理的网络与设备信息。音视频流原则上在终端之间传输，我们不主动存储通话内容，除非法律另有规定或你另行授权。

1.4 文件、网盘与协作工具

  • 你上传至聊天、群文件、个人网盘的文件及其元数据（文件名、大小、类型、上传时间等）；
  • 日历日程、笔记、收藏等你主动创建或保存的内容。

1.5 设备权限

在提供相关功能时，我们可能申请以下系统权限，你可以在设备或应用设置中管理授权：

  • 相机、麦克风：用于拍摄、扫码、语音消息与音视频通话；
  • 相册/存储：用于发送与保存图片、文件；
  • 通知：用于消息提醒与系统通知；
  • 网络：用于连接服务器与实时推送。

1.6 依法无需征得同意的情形

根据法律法规，以下情形收集、使用个人信息无需另行征得你的同意：

  • 与国家安全、国防安全、公共安全、公共卫生、重大公共利益直接相关的；
  • 与犯罪侦查、起诉、审判和判决执行等直接相关的；
  • 出于维护你或其他个人的生命、财产等重大合法权益但又很难得到本人同意的；
  • 你自行向社会公众公开的个人信息；
  • 从合法公开披露的信息中收集的，如合法新闻报道、政府信息公开等；
  • 签订和履行合同所必需的，或维护产品与服务安全稳定运行所必需的；
  • 法律法规规定的其他情形。

二、我们如何使用信息

我们仅会在以下目的范围内使用你的个人信息：

  • 提供、维护与改进 LinkX 的注册登录、消息收发、群组、通话、文件网盘等功能；
  • 通过 HTTP 与 WebSocket 实现消息同步、在线状态与通话信令；
  • 进行身份验证、安全风控、敏感词过滤与违规内容处置；
  • 响应你的咨询、投诉与技术支持请求；
  • 遵守法律法规、监管要求或司法/行政机关依法提出的要求；
  • 经你同意的其他用途。

我们不会将个人信息用于本政策未载明的其他目的。如需用于新的目的，我们将再次征得你的同意。

三、信息的存储

3.1 存储地点

我们在中华人民共和国境内收集和产生的个人信息，将存储在境内服务器。目前我们不会将你的个人信息传输至境外。若将来因业务需要向境外提供个人信息，我们将依法履行评估、告知与征得同意等义务。

3.2 存储期限

  • 账号信息：在你使用服务期间持续保存；注销账号后，我们将依法删除或匿名化处理，法律法规另有规定的除外；
  • 聊天记录与文件：保存期限取决于你的使用行为、功能设置及组织管理策略，你可在客户端删除消息或文件；
  • 日志信息：通常保存实现安全审计与故障排查所需的最短期限。

3.3 停止运营

若 LinkX 产品或服务停止运营，我们将提前公告或通知，并依法对所持有的个人信息进行删除或匿名化处理。

四、信息安全

我们采取符合业界标准的安全措施保护你的个人信息，包括但不限于：

  • 传输加密（HTTPS/WSS）与访问控制；
  • 双 Token 鉴权、密码加密存储与登录风控；
  • 敏感词过滤、操作审计与权限分级（RBAC）；
  • 对存储于 MinIO 等对象存储的文件进行访问鉴权。

互联网环境并非绝对安全。请你妥善保管账号与密码，使用复杂密码并避免在公共设备上保持登录。如发现账号异常，请立即联系我们。

如发生个人信息安全事件，我们将按照法律法规要求，及时告知事件基本情况、可能的影响、已采取或将要采取的措施、你可自主防范的建议及补救措施，并按监管要求上报。

五、信息共享、转让与公开披露

5.1 共享

我们不会向第三方出售你的个人信息。仅在以下情形可能共享：

  • 获得你明确同意后；
  • 根据法律法规、诉讼、仲裁或行政机关、司法机关依法提出的要求；
  • 与授权合作伙伴共享：仅为实现本政策目的所必需，且受严格保密与安全约束（如基础设施托管、短信验证等）。

5.2 转让

我们不会将个人信息转让给任何公司、组织或个人，但涉及合并、收购、重组或破产清算时，如涉及个人信息转让，我们将要求受让方继续受本政策约束，或重新征得你的同意。

5.3 公开披露

我们仅会在获得你明确同意，或基于法律强制性要求的情况下公开披露你的个人信息。

六、你的权利

按照中国相关法律法规，你对个人信息享有以下权利：

  • 查阅与复制：你可在「设置」中查看账号资料、头像、昵称、LinkX ID 等信息；
  • 更正与补充：你可自行修改部分资料，或通过联系我们协助更正；
  • 删除：你可删除消息、文件或申请删除特定个人信息；在符合法定条件时，可要求我们删除；
  • 撤回同意：你可在设备或应用设置中关闭相机、麦克风、通知等权限，撤回后不影响此前基于授权的处理；
  • 注销账号：你可在应用内申请注销。注销后我们将停止提供服务，并依法删除或匿名化你的个人信息；
  • 获取副本与投诉：你可联系我们获取个人信息副本，或向监管部门投诉举报。

为保障安全，我们可能在处理你的请求前验证身份。我们将在合理期限内（通常不超过 15 个工作日）答复。

七、Cookie 与同类技术

LinkX 桌面客户端主要使用本地存储与 Token 机制维持登录状态。若你访问 Web 管理端或相关网页，我们可能使用 Cookie 或类似技术记住语言偏好、会话状态。你可通过浏览器设置管理 Cookie，但可能影响部分功能使用。

八、未成年人保护

LinkX 主要面向企业及成年用户。若你未满 18 周岁，请在监护人指导下阅读本政策，并在取得监护人同意后使用本服务。

我们仅在法律允许、监护人明确同意或为保护未成年人所必需的情况下处理未成年人个人信息。若发现在未获监护人同意的情况下收集了未成年人信息，我们将尽快删除。

九、本政策的变更

我们可能适时修订本政策。若变更会导致你的权利发生重大减损，我们将在生效前通过应用内通知、网站公告或其他合理方式提示你。若你不同意变更后的政策，可停止使用并注销账号；若你继续使用，即视为你接受修订后的政策。

十、联系我们

如对本政策有任何疑问、意见或建议，可通过以下方式联系我们：

  • LinkX 客户端：「设置」→「关于」→ 问题反馈；
  • Gitee Issues：https://gitee.com/yangleduo7788/link-x/issues；
  • 项目主页：https://gitee.com/yangleduo7788/link-x。

我们将在收到你的反馈后 15 个工作日内予以回复。

本政策是《LinkX 软件许可及服务协议》的重要组成部分，与其具有同等法律效力。
