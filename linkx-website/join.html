欢迎加入 LinkX 社区

LinkX 由 Yangleduo 发起并维护，采用 MIT 开源协议。项目涵盖桌面客户端、运营管理后台与 Spring Boot 后端，适合学习现代 IM 架构、全栈开发与团队协作实践。

开源开放

源码托管于 Gitee，欢迎 Fork、Star 与 Pull Request。

技术成长

涵盖 Vue 3、Electron、Netty WebSocket、WebRTC 等主流技术栈。

协作共建

Issue 讨论、代码评审与文档共建，与社区一起成长。

真实场景

面向企业 IM 真实需求，功能完整、可本地部署联调。

你可以这样参与

  • 代码开发：修复 Bug、实现新功能、优化性能与体验。
  • 文档完善：补充使用说明、架构文档、部署指南与 FAQ。
  • 测试反馈：在不同平台安装体验，提交复现步骤与改进建议。
  • 设计贡献：UI/UX 优化、图标与视觉资源、交互原型建议。
  • 社区运营：回答问题、整理 Issue、推广项目与撰写技术文章。

没有编程经验也可以参与——清晰的 Bug 报告、文档纠错和功能建议同样非常有价值。

代码贡献流程

  1. 访问 Gitee 仓库，Fork 项目到你的账号。
  2. 克隆 Fork 后的仓库到本地，创建功能分支（如 feature/xxx 或 fix/xxx）。
  3. 按照项目规范完成开发与自测，确保现有功能不受影响。
  4. 提交 Pull Request，描述变更内容与测试情况，等待维护者 Review。
  5. 根据 Review 意见修改后合并，你的贡献将出现在 CHANGELOG 与贡献者列表中。
提交规范

Commit 信息请简洁明确；PR 尽量保持单一职责、变更范围可控。涉及数据库变更请通过 Flyway 脚本管理，勿手改生产库。
